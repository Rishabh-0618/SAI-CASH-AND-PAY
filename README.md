# Sai Cash & Pay (demo)

Demo e-commerce store and admin for a Worthing cash & carry. All products, prices, orders and customers are fictional. No real payments or alcohol delivery.

- Store: open `index.html`
- Admin: `index.html#/admin` (demo password: `demo`)

## Publish on GitHub Pages
1. Create a new repository and upload `index.html` and `README.md`.
2. Settings > Pages > Deploy from a branch > `main` / root > Save.
3. Your site appears at `https://YOUR-USERNAME.github.io/REPO-NAME/`.
